# Water Drinking Reminder
A simple Python application that reminds you to drink water at regular intervals using desktop notifications. I created this project to practise Python programming, work with external libraries, and build a useful everyday application.

## 📊 Project Overview 
This application that sends desktop notifications at regular intervals to remind users to stay hydrated. The application uses the time module to manage reminder intervals and the plyer library to display notifications. Users can customise the reminder frequency by changing the interval passed to the function.

## ✨ Features
- Sends desktop notifications reminding you to drink water.
- Allows you to set the reminder interval in minutes.
- Uses an infinite loop to repeat reminders automatically.
- Uses plyer to display desktop notifications.
- Uses time.sleep() to wait between reminders.
- Can be stopped using Ctrl + C in the terminal.

## 🛠️ Technologies Used
- Python
- `time` module
- `plyer` library
